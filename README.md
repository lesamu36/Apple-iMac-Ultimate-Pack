# Apple iMac Ultimate Pack

Version 1.0 Stable

## Description

Apple iMac Ultimate Pack is a Bash installer that optimizes Linux Mint XFCE for older Apple iMac computers.

The installer is designed for:

- Home use
- Office work
- Web browsing
- Documents
- Multimedia

## Features

- System backup
- Hardware detection
- Performance optimization
- XFCE optimization
- Firefox optimization
- Desktop optimization
- Services optimization

## Requirements

- Linux Mint 22.x XFCE
- sudo privileges

## Installation

```bash
chmod +x install.sh
sudo ./install.sh
```

## Uninstall

```bash
sudo ./uninstall.sh
```
